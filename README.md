# kubernetes-lsp

This LSP is designed for Kubernetes built-in resources and custom resource definitions

## Functionality

- Validation of built-in Kubernetes resources
- Validation of Kubernetes custom resource definitions
- Suggestions
- json encode and decode of ide sended things
- Server supports stdin and stdout
